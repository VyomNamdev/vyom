## Pipeline (same for every video)
Character bible → Topic → Script & hook → Shot list + image prompts → Voice → Edit → Thumbnail & title → Upload → 48-hour review

Stage 1 Channel bible (once) → Stage 2 Plan / Case file → Stage 3 Script → Stage 4 Shot list → Stage 5 Voice script → Stage 6 Packaging.
Claude **stops after every stage** and waits for "approved". Nothing ships below 8/10 on the D4 scorecards.
