# Episode template — Paycheck to Plenty
Copy this folder to `episodes/NN-short-slug/` for each video. Fill one file per stage, in order.
Do not start the next file until the owner writes "approved" on the current one.

| File | Stage | Done when |
|---|---|---|
| 02_plan.md | Stage 2 — Episode plan | Format (F1-F6) named; 3 hooks + 5 titles scored, winners 8+/10 |
| 03_script.md | Stage 3 — Script (~160 wpm) | Word count stated; every number marked [SOURCE?] and verified by owner |
| 04_shotlist.md | Stage 4 — Shot list (3-6 s per shot) | Every shot has a full image prompt or recording instruction |
| 05_voice.md | Stage 5 — Voice script | Pauses, emphasis, phonetics, music + SFX cues |
| 06_packaging.md | Stage 6 — Packaging | Title, 3 thumbnails scored, description, tags, pinned comment, Shorts |
| sources.md | All stages | Every fact/number → link, checked by owner (date) |
| review-48h.md | After upload | Section 7 metrics filled in |

Media produced for the episode goes in `images/`, `audio/`, `screen/`, `render/` inside the episode folder.
